LoanMaster 2.1.0 brings payroll reconciliation, month-end close and customizable documents to the Windows desktop app.

### Downloads

- **LoanMaster-Setup-v2.1.0.exe** installs or upgrades LoanMaster on Windows.
- **LoanMaster-Portable-v2.1.0.exe** runs directly without an installer.
- **SHA256SUMS.txt** lists the SHA-256 checksum for each executable.

### Upgrade an existing journal

Back up your journal and open a copy in 2.1.0 first. This version upgrades journals at schema 12 or 13 to schema 14. Compare balances and member statements before moving your office to the upgraded copy. To return to an earlier release, use the pre-upgrade backup. For journals older than schema 12, first open a copy in the [legacy Windows release](https://github.com/Eric13587/loanmaster-sacco/releases/tag/loan).

### Changes

- Build custom PDF and Excel documents with ordered columns, editable headings, and the organization logo.
- Prepare email drafts for individual members or a batch, with each member's own statement attached.
- Reconcile payroll and bank receipts, export a signed close, and require a second officer to reopen a period.
- Assign operator roles and approve exit payouts using distinct operating system accounts.
- Configure and verify secondary backups. Posted cash amounts have integer-cent records.
